# Agent-to-agent text — ASD-STE100

Canon: `.claude/rules/00-agent-comms.md`. Read it and obey it before you write text for another model.

Core: English; one word has one meaning; procedure sentence max 20 words; imperative and active voice; only the
facts that the recipient must have to act; explanations only on request.
Task: `GOAL` · `CONTEXT` · `CONSTRAINTS` · `ACCEPTANCE` · `RETURN`. Report: `RESULT` · `EVIDENCE` · `OPEN`.
