## Что получилось

```
Mac/телефон ──WireGuard → 173.212.238.170:51820/udp──▶ VPS wg0 10.77.0.1
  split: AllowedIPs 10.77.0.0/24      — через VPS идёт только t-boards
  full:  AllowedIPs 0.0.0.0/0, ::/0   — весь трафик, выход в интернет с адреса VPS (DNS 1.1.1.1, 9.9.9.9)

https://d4dev.admin.hrhelper.space ─(/etc/hosts → 10.77.0.1)─ wg0 REDIRECT 443→8443 (только -d 10.77.0.1)
    ──▶ tls (nginx, host network, 10.77.0.1:8443) ──▶ app 127.0.0.1:5180 ──▶ postgres 16 (свой том)
                                                      backup: pg_dump каждые 2 ч, хранит 3 дня
full, всё остальное ── цепочка TB-WG ── MASQUERADE через внешний интерфейс ──▶ интернет
Mac LaunchAgent ── ssh по туннелю, forced `cat latest.dump` ──▶ ~/t-boards-backups (14 дней)
```

- **Доступ.** Только `d4dev.admin.hrhelper.space` требует туннеля. Публичный `:443` остаётся за edge nginx продукта:
  без туннеля этот адрес отдаёт сертификат продукта, а не t-boards. Остальные поддомены работают без VPN, как раньше.
- **Режимы.** Серверный конфиг одинаков для обоих режимов, различается только `AllowedIPs` у клиента. Поэтому один
  peer Mac (10.77.0.2) держит два туннеля в приложении WireGuard с одним ключом: «t-boards» (split) и
  «VPS-выход» (full). Включён один из двух.
- **Правила.** `/etc/wireguard/t-boards-rules.sh` вешается на `PostUp`/`PreDown` и снимается целиком.
  - Цепочка `TB-WG` подключена в `FORWARD` и `DOCKER-USER`. Она пропускает wg0 → внешний интерфейс и ответы на него.
    Опубликованные порты продукта доступны через Docker DNAT. Всё остальное из wg0 отбрасывается.
  - Форвардинг задаёт `/etc/sysctl.d/99-t-boards-wg.conf`.
  - Повторный запуск `wg-setup.sh` добавляет peer и обновляет wg0 из первого набора, ничего не дублируя.
- **Сертификат.** Let's Encrypt по HTTP-01 через certbot-тома продукта. Sidecar продукта продлевает и наш
  сертификат, `tls` перечитывает его раз в 12 ч.
- **Секреты.** Только файлы `*_FILE` в `/opt/t-boards/secrets` (N-007): пароль БД, `auth_secret`, а также
  необязательные `notion_token` и `notebook_llm_key`. Регистрация и гостевой доступ выключены. Вход — admin / admin,
  его засевает `install.sh`.
- **Продукты.** `install.sh` засевает три продукта из `seed/products.json`: HR Helper / Lavaeon, aiBoards&eval,
  Financial terminal. Вместе с ними — 5 проектов и 42 карточки плана, включая TB, SE и OPS. Сид только добавляет
  недостающее: правки в UI обновление не откатывает.
- **Зеркало Notion.** Включает `mirror-setup.sh`. Продукт HR Helper он находит сам, токен вводится на VPS скрыто
  и до меня не доходит.
- **Блокнот.** Mac-агент (`mac/notebook-agent.sh`) синхронизирует документы и считает эмбеддинги локальной Ollama.
  Модель для ответов подключается ключом `notebook_llm_key`. Подробности — `impl-b3-notebook.md`.

Файлы и назначение — `app/deploy/vps/README.md`.

## Известные ограничения

- **Телефон.** На телефоне нет `/etc/hosts`, поэтому имя `d4dev.admin.hrhelper.space` ведёт на публичный адрес и
  edge nginx продукта. Режим full с телефона работает как обычный VPN, но t-boards по имени с него пока не открыть.
  Решение — DNS на VPS для туннеля (отдельный шаг после пилота).
- Ключ забора бэкапов принимает подключения только с 10.77.0.2 (Mac).
- Загрузка картинок требует S3 (`isStorageConfigured`). S3 нет, поэтому загрузки выключены. Все данные хранятся в
  Postgres и попадают в дамп.
- `NOTIFICATION_SECRET_ENCRYPTION_KEY` читается только из env. Каналы уведомлений с секретами выключены, пока у
  переменной нет `_FILE`.
- Лимиты памяти временные: app 1 ГБ, postgres 256 МБ, tls 64 МБ, backup 128 МБ. Замера K-6 до деплоя не было: окно
  сократили до 01.11. Замер — `docker stats` на VPS в первые сутки, потом правка `compose.yml`.
- С самого VPS адрес `10.77.0.1:443` попадает на edge nginx (OUTPUT DNAT Docker). Локальным клиентам на VPS — боту,
  раннеру — нужен `10.77.0.1:8443` или `127.0.0.1:5180`.
- `install.sh` требует ≥ 900 МБ свободной памяти и ≥ 3 ГБ диска в `/opt`. Иначе он останавливается до любых изменений.
- Обновление идёт тем же путём: новый бандл → `install.sh`. Перед `up` скрипт снимает дамп `pre-<tag>-*.dump` и
  сохраняет строки `NOTION_MIRROR_*` и `NOTEBOOK_LLM_*` из прежнего `.env`.
