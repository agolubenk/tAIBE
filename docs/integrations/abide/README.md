## Что это

- **Не статический линтер.** abide — хуки агента (Claude Code, Codex, OpenCode, Pi): после каждой правки и в конце хода
  он задаёт внешней модели-классификатору Jev (TypeSafe) по одному вопросу на правило и получает вероятность
  нарушения. От 0,8 агенту приходит просьба исправить.
- **Правила** — из прозы `AGENTS.md`/`CLAUDE.md`: abide компилирует их в `.abide/rubric.json` с помощью Claude Code.
  Встроенных правил нет. Правила, которые может проверить линтер, abide отдаёт линтеру.
- **Данные:** изменённые строки уходят в TypeSafe или через Vercel AI Gateway, по ключу пользователя. Срок хранения —
  договор с TypeSafe; нулевое хранение — только на корпоративном тарифе.
- **Установка** пишет хуки в `~/.claude/settings.json` (или в проект с `--project`).
- **Команды для замера:** `abide audit <пути>` (существующий код), `abide replay claude` (прошлые сессии), `--json`.
- **Цена по замеру авторов** (2026-09-18): 1000–1600 входных токенов на проверку, около $0,00005, около 300 мс.
- **Лицензия** — MIT (`t-boards-spec.md:419`, сверено с репозиторием 14.11).

## На что ложится в tAIBE

| Требование | Что предполагает спека | Что даёт abide |
|---|---|---|
| R-070: abide на каждом PR | задача CI на раннере GitHub (S23-2) | хук в сессии агента; в CI нужен ключ TypeSafe и отправка диффа наружу |
| R-071: статические проверки — не на Mac, LLM — на Mac | abide считался статическим | это вызов внешней модели: по R-071 место — Mac |
| R-074, правила 2, 4, 6, 7 для tAIBE | «правила abide» (S23-3) | все четыре проверяет линтер, и abide отдал бы их линтеру |

Правила R-074 для tAIBE без abide (проверено):
- (6) `dangerouslySetInnerHTML` — уже `react/no-danger: error` в `boards/vite.config.ts` (oxlint, `pnpm lint`), строже,
  чем «без DOMPurify»;
- (2) выборка Drizzle без `limit`, (4) `process.env` вне модуля конфигурации, (7) Telegram без `parse_mode` — проверки
  по коду: правило oxlint или проверка в `infra/checks/`, без модели и без отправки кода наружу.

Пересечение со слоем: антигены `eval/pipeline/genome/antigens.json` уже дают агенту урок по шаблону действия,
бесплатно и детерминированно; хуки `.claude/hooks/` — свои, abide добавил бы ещё четыре.
