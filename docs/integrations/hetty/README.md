## Что это

HTTP-прокси для ручного исследования безопасности (аналог Burp): перехват, история, повтор запросов, веб-интерфейс.
Go, лицензия MIT. В спеке досок — R-075 («hetty — только локально», `boards/docs/t-boards-spec.md:152`), карточка
TB-164 (TB-24 S24-1).

## Почему не берём

Проверено 14.11.2026 через GitHub API:

| Признак | Значение |
|---|---|
| Последний релиз | `v0.7.0`, 2022-03-29 |
| Коммиты с 2025-01-01 | 7, последний — 2026-06-27 |
| Репозиторий | не в архиве, лицензия MIT |

- Релизов нет 4,5 года. Прокси разбирает недоверенный трафик (HTTP/1.1, HTTP/2, TLS), и уязвимость в разборе без
  выпуска исправлений — риск именно для машины владельца.
- Установка — бинарник 2022 года или сборка из исходников без релиза. Ни то ни другое нельзя закрепить на версии,
  которую кто-то поддерживает.
- Задача S24-1 решается так же или лучше живым инструментом (mitmproxy 12.3.1 от 2026-10-25): перехват, повтор,
  веб-интерфейс, только `127.0.0.1`.
