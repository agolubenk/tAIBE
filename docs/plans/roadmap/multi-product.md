## Цель (слова владельца, 02.11)

tAIBE — одна отдельная папка на Mac, надстройка над продуктами, которые владелец выбирает:

- внутри tAIBE — разделение по продуктам: настройки, данные, состояние;
- над конкретным продуктом tAIBE работает в его локальной папке;
- данные tAIBE доступны из папок подключённых продуктов;
- на сервере — связка с продуктами по id (доски: продукт = workspace) и их ориентиры.

## Порядок и правила

- Фазы идут по номеру. M4 можно делать параллельно с M2–M3. Из M6 стенд d4dev можно переключить сразу после M0,
  остальное в M6 — после M1.
- Каждая фаза проверяется сначала в worktree (`.claude/rules/07-worktrees.md`, «Испытательный контур»), затем
  PR → CI → мёрж. Живые сессии берут новую версию на границе единицы работы.
- Обратимость: у каждой фазы, которая переносит данные или меняет запуск, есть скрипт отката. Данные переносятся
  через `mv` в бэкап, а не удалением.
- Что фаза затрагивает в репозитории продукта (HR), идёт отдельным PR в HR. Такой PR должен попадать в
  `paths-ignore` деплоя (`docs/**`, `.claude/**`, `**/*.md`), либо его вливает владелец по плану деплоя.
